Приложение лежит на https://artemkruhly.github.io/vertical-videos/.

Использовал технологии:

-Vanilla JavaScript (ES6+)

-HTML5 Video API

-CSS3

-Pointer Events (для единой реализации мыши и тач ивентов)

-IntersectionObserver(для оптимизации воспроизведения видосов)

-requestAnimationFrame (для плавности анимаций)

Компонентная архитектура без использования фреймворков. Изначально хотел реализовать через модули es6 (import/export), было бы похоже на компоненты Vue или React, но надо было бы еще сделать сервер.

utils/format.js - форматирование чисел к общему формату

Feed.js - Компонент управления главным видео.

VideoSlide.js - главный компонент для одного видео. Клики, оверлеи

По другим компонентам структурно понятно для чего.

Воспроизводится только активное видео. Сделал Лодер пока не видео не загружено.

Реализованы пауза/плей по нажатию, перемотка видео по плейбэку с показом текущего времени и общего, дабл клик - лайк, открытие комментов, share сделал как просто блок без реализации.

Поддерживается десктопная версия и мобильная.
